## 验证方式

首批 A01–A06 结果：后端 **129 项测试全部通过**；Ruff 检查与全量格式检查通过；Web 类型检查与 Next.js 16.4.3 生产构建通过；生产依赖审计为 **0 high、0 critical、4 low**。这些结果在本地得到，远端 CI 尚未触发。当前验证使用 Python 3.13 和 Node.js 26，CI 配置使用 Python 3.12 和 Node.js 22，远端矩阵仍需实际运行确认。

续批 A07–A08 结果：新增 **21 项**身份与授权测试，完整后端 **150 项全部通过**；Ruff 与全量格式检查通过，实施文档链接检查通过。本批没有前端变更，因此未重复运行前端构建；先前构建结果不能作为未来登录界面的验收。

续批 A09–A11 结果：新增 **25 项**回归，完整后端 **175 项全部通过**；Ruff 与全量格式检查通过。其中工作空间问答 13 项、Langfuse 身份传播 1 项、MinerU 契约与失败保留 11 项。测试未调用真实供应商，浏览器与 MinerU 云端实测仍待完成。

续批 A12–A13 结果：新增 **22 项**私有阅读状态与集合回归，完整后端 **197 项全部通过**；Ruff、全量格式与差异检查通过。包括并发修订冲突、删除后版本不重置，以及数据库写入故障时集合名称/成员/修订号/审计全部回滚。没有前端变更、真实论文或外部供应商调用。

续批 A14–A15 结果：旧单用户队列及其专用 Worker / HTTP 入口已移除，新上传统一由工作空间队列处理；按照用户要求，旧任务与事件不迁移保留，启动新版本时删除，PDF、解析产物和文献数据保留。本批新增 **21 项**统一队列回归并替代旧队列 1 项，全量后端 **217 项全部通过**；Ruff 与全量格式检查、Web 类型检查和生产构建通过。CLI 已统一提交，旧浏览器上传控件移除，新的浏览器身份与上传流程待接入。后续 A16 查明此前测试收集会初始化默认数据库，默认库已是 v4；此处“尚未执行迁移”的原判断已更正，测试已改用临时目录。

续批 A16–A17 结果：浏览器会话令牌登录、退出、工作空间选择、统一上传和认证 PDF 已接通；OIDC、问答/SSE 与个人状态的工作空间 UI 仍待实施。后端新增 **4 项**并达到 **221 项全通过**，前端首次建立 **19 项**客户端回归并加入 CI，TypeScript 与生产构建通过。以一次性合成身份和 PDF 完成浏览器上传入队、取消、工作空间隔离、下载、刷新后重新登录和注销后令牌失效验收；未调用付费供应商。修复测试收集触及默认数据目录的问题，详见 A16。

续批 A18–A20 结果：工作空间主流程已形成上传→读取→问答/多轮→历史/SSE/引用/导出→私有阅读记录/集合闭环。新增 2 项运行模式后端回归与 12 项客户端/SSE 回归，本地后端 **223 项**、前端 **31 项**通过。真实 MinerU/SiliconFlow 联调使用自编两页文档，一次解析、两轮问答完成；两轮回答生成合计 1515 tokens，账单未对账。真实浏览器验证双窗口 409 草稿保留、跨用户/空间隔离、刷新恢复、集合到问答，以及首页按模式分流。证据与未验证项见 A20；不代表整体生产计划完成。
