# A03：上传资源限制与失败清理

日期：2026-10-25。状态：本项已实现；解析沙箱与网关资源限制待后续交付。

## 实现结果

在提交付费解析任务前，验证扩展名、PDF 文件头、实际可解析性、加密状态、页数与上传字节数。无效文件返回 415/422，超过字节或页数限制返回 413，不入摄取队列。

`api/uploads.py` 负责有界写入与校验；异常和取消路径清理临时文件，并关闭 UploadFile。`api/main.py` 保留哈希去重，入队失败清理文件，重复上传只保留已有任务的文件。

## 配置

| 配置 | 默认值 | 作用 |
| --- | --- | --- |
| SCHOLARRAG_UPLOAD_MAX_BYTES | 52428800 | 单 PDF 最大 50 MiB |
| SCHOLARRAG_UPLOAD_MAX_PAGES | 500 | 单 PDF 最大页数 |

配置已加入 `.env.example`，通过 Settings 校验为正数。页数校验不会调用 OCR 或模型。

## 验收

`tests/test_upload_limits.py` 验证无效正文、伪造 PDF 文件头、大小超限、页数超限、文件关闭、临时文件清理、HTTP 层先校验后入队和重复上传去重。使用本地生成的合成 PDF，不含真实论文。

```bash
uv run --extra dev --extra observability pytest tests/test_upload_limits.py -q
```

## 限制与下一步

本轮结果：5 个新增上传用例通过，完整后端 129 项通过；未使用真实 PDF 或外部解析 API。

FastAPI multipart 解析可能在进入此函数前已经将请求写入临时空间，因此此限制不能代替反向代理的请求体、速率、并发和临时磁盘限制。PDF 页数验证也不是恶意文档沙箱，没有完整限制 CPU、内存或解析时间。

后续补齐入口限流、受限解析进程、供应商下载/解压预算、总存储配额，以及独立 Worker 中的取消和清理。当前上传与任务仍是个人单用户模型，去重键尚未加工作空间。
